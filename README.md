# 🚀 Camp-X

A next-generation college companion platform designed to centralize student resources and improve campus life.

## ✨ Features

- 📢 Campus Complaints Portal  
- 📚 Notes & Academic Resources  
- 🧾 Lost and Found System  
- 📅 Attendance Tracking  
- 🏫 College Updates & Notices  
- 👨‍🎓 Student-Friendly Dashboard  

## 🛠️ Tech Stack

- React.js  
- TypeScript  
- Vite  
- Firebase / Backend APIs  
- CSS / Tailwind (if used)

## 🎯 Purpose

To solve common college student problems through one smart platform.

## 📈 Impact

Used by 100+ active users and built as a real-world student solution.
